# Using AI tools with this scaffold

Any AI tools are allowed: Genie Code / Databricks Assistant in the workspace, your own assistant, an IDE.

Suggestions:
- Give your assistant this README, the engagement log and the `docs/prod_job_configs/` exports first.
- Ask the workspace assistant to explain the bundle and each notebook with the file open.
- Get the exact schema from `information_schema.columns` before asking for queries, so the queries use real column names.
- Verify every number an assistant gives you by running the query yourself.
- Never paste credentials or tokens into any AI tool.
